# SteadyView for WoW: Forever

**IMPORTANT — Installing from GitHub:** After downloading and extracting GitHub's source archive, manually rename the folder `steadyview-main` to **`steadyview`** (remove `-main`) before copying it into `Interface/AddOns/`. The separately packaged installation ZIP already contains the correct `steadyview` folder and needs no rename.

Version 0.2.0-beta.

## Testing status
The addon is tested in WoW: Forever by its user after each build. Version 0.2.0-beta is **awaiting user verification**; code review alone does not establish in-game compatibility.

## Profiles in 0.2.0
The Profiles tab now includes a dropdown listing saved profile names. Select an existing profile then choose **Load selected**. Saving a new profile updates the list immediately. Profiles are stored in `SteadyViewDB`.

## Installation
Use the packaged release ZIP, which contains exactly `steadyview/` at its root. Extract this folder into `Interface/AddOns/`. The source archive automatically generated by GitHub uses a different folder name; do not install that archive unchanged.

## Changes in 0.1.6
- Smooth circular reference dots use a bundled 128x128 alpha-blended `Circle.tga` instead of striped rectangles or unsupported mask APIs.
- Each reference bar (left, right, top, bottom) has its own on/off control, with migration from previous side-selection settings.
- Movement extra darkening and turn protection range from 0.05 to 1.60, converted to safe display alpha (0 to 1).
- Settings are saved in SteadyViewDB; in-game testing still required.

## Commands
`/steadyview` opens settings; `/steadyview edit` enables dot dragging; `/sv status` shows motion diagnostics.

## Notes
Camera motion detection is client-dependent. This addon is experimental and is not medical treatment.

- Movement protection values above 1.0 extend the peripheral darkening further into the screen when triggered.
- Focus size extends to 120 pixels and offers a filled circular Dot option.


## v0.1.7 changes
- Added cross marker point size (1–48).
- Corrected Focus shape button spacing.
- Five-second darkening test now uses elapsed frame time, previews current protection intensity, and renders immediately.


## v0.1.9 test improvements
- The five-second darkening preview uses the current Speed and Turn strengths together, without an artificial minimum.
- A large on-screen 5-to-0 countdown appears during the preview.
- The timer measures actual frame time, and the preview ignores live movement while active.


## 0.1.9 focus rendering
Circle and Cross points now use Circle.tga, just like Dot.
